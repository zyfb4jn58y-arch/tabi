Add to Tabi from any website

Save a hotel booking, ticket, restaurant or place into Tabi in a couple of taps. The button reads the page you're on and copies the details for Tabi. Nothing is sent anywhere.

1On a booking page, tap Add to Tabi
2Check what it found and tap Copy for Tabi
3In Tabi, tap + then Paste from a site

Safari on iPhone Set up once

The button lives in your Favourites, so it's one tap from the address bar.

  1. Tap Copy the button code.
  2. Still in Safari, tap Share (or ••• then Share), then Add to Favourites, then Save.
  3. Open Bookmarks (the book icon), go to Favourites, tap Edit, then tap the bookmark you just saved.
  4. Change the name to Add to Tabi. Clear the address underneath, tap and hold, choose Paste, then tap Done.
To use itOn a booking or ticket page, tap the address bar. Your Favourites appear underneath. Tap Add to Tabi.

Brave on iPhone Set up once

Brave runs the same button from its bookmarks.

  1. Tap Copy the button code.
  2. In Brave, bookmark any page (tap •••, then Add Bookmark).
  3. Open your Bookmarks, tap Edit, then tap that bookmark.
  4. Name it Add to Tabi, replace the address with the code you copied, and save.
To use itOn a booking or ticket page, open Bookmarks and tap Add to Tabi.

Safari's Share button Optional

Prefer the Share button? Make a Shortcut that does the same thing. It copies straight away, with no panel to tap.

  1. Tap Copy the Shortcut code.
  2. Open the Shortcuts app, tap +, and name the new shortcut Add to Tabi.
  3. Add the action Run JavaScript on Web Page. Delete the sample code inside it and paste yours.
  4. Add Copy to Clipboard, then Show Notification with the text Copied for Tabi.
  5. Open the shortcut's settings (the ⓘ button), turn on Show in Share Sheet, and set it to receive Safari web pages.
To use itOn a booking page in Safari, tap Share, then Add to Tabi. The first time on each site, iPhone asks you to allow it.

Good to know

Confirmation pagesSelect the booking details first (dates, price, booking number), then tap Add to Tabi. It reads what you selected.
Booking PDFsSave the PDF to Files, then in Tabi tap + and Import a PDF. It fills in the details and can keep the PDF with the place to show at check-in.
Booking emailsCopy the email text, then in Tabi tap + and Paste from a site. It picks out dates, times, the total and the booking reference.
Tickets and QR codesTake a screenshot of the ticket, open the place in Tabi, and tap Add ticket. It opens full screen on white, ready to scan, even offline.
Already planned it?Open that place, tap Edit, then Paste from a site. The booking dates, price and reference are added to it.
Private by designThe button only runs when you tap it, only reads the page you're on, and only puts the details on your clipboard.
